# Learn Git Curriculum

A hands-on, self-contained curriculum to take you from Git absolute zero to advanced mastery.

## How to Use This Repository

1. **Read the Theory**: Start in the `00-theory/` folder for each phase.
2. **Do the Exercises**: Go to `01-exercises/` and run the provided `setup.ps1` script to generate a safe sandbox repository in `practice-areas/`. 
3. **Check Your Work**: If you get stuck, look at the corresponding file in `solutions/`.
4. **Fire Drills**: At the end, try the broken-repo scenarios in `02-scenarios/` to test your recovery skills.

## Recommended Order & Time Estimates
